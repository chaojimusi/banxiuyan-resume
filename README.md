# 班秀岩 · 个人简历（静态网页）

将 Word 简历文档 `班秀岩-个人简历.docx` 制作为纯静态、响应式的个人简历网页。无需任何构建工具，双击 `index.html` 即可在浏览器中打开。

## 线上地址

| | |
| --- | --- |
| GitHub 仓库 | https://github.com/chaojimusi/banxiuyan-resume |
| GitHub Pages | **https://chaojimusi.github.io/banxiuyan-resume/** |

## 内容来源

- **源文件**：`班秀岩-个人简历.docx`
- **转换方式**：直接解析 Word 的 OOXML（`word/document.xml`），逐段提取标题、正文、项目符号与表格内容后重建为 HTML 语义结构
- **原文档资源**：文档正文内**不含任何图片与超链接**，因此页面没有需要相对路径引用的图片；唯一的静态资源是 `assets/img/favicon.svg`，已按相对路径引用

### 内容保真

页面严格按原文呈现，**未删减、未改写任何事实性内容**，包括：

- 求职意向：数据处理 / 运营助理 / 大数据相关岗位
- 教育背景：大连财经学院 · 管理学院，2023 年 9 月 — 2027 年 6 月（预计）
- 实践经历：线下咖啡店 · 产品研发与销售（兼职/实践）下的 3 条描述
- 专业技能：大数据基础、数据分析、数据库、办公软件 4 项及其完整描述
- 求职方向全文

上述内容已通过脚本与 `word/document.xml` 逐句比对，**17 条原文语句全部逐字命中（含标点）**。

技能项在版式上被拆成「标签 + 描述」两段（例如 `<h3>大数据基础：</h3>` + `<p>了解大数据基本概念与技术体系，具备数据处理的基础认知；</p>`），这只是把原有的标签结构显式化为标题 markup，字句与标点均未改动。

原文档中未提供的信息（如联系方式、证件照）未做任何补写。

## 本地运行方式

无任何依赖、无构建步骤，三种方式任选：

```bash
# 方式一：直接双击 index.html（file:// 协议下同样正常工作）

# 方式二：Python 静态服务器
python -m http.server 8000

# 方式三：Node.js
npx serve .
```

之后访问 <http://localhost:8000>。

## 设计说明

- **配色**：沉稳的蓝（`#2c5f8d`）为主色，暖褐（`#b6722f`）作点缀，中性灰铺底，整体冷静克制，契合简历场景
- **字体**：使用系统字体栈（PingFang SC / Microsoft YaHei / Segoe UI 等），不引入任何外部字体，离线可用
- **响应式**：桌面端导航横向排布、技能双栏；窄屏下导航自动换行并可横向滚动，正文留白与字号同步收紧
- **动效**：仅保留必要的过渡效果（悬停、主题切换），未使用滚动动画或视差等复杂效果；同时遵循 `prefers-reduced-motion` 偏好设置
- **打印**：提供专门的打印样式，右上角按钮可直接调用 `window.print()` 导出 PDF

## 部署到 GitHub Pages

仓库已包含 `.nojekyll`，Pages 源配置为 `main` 分支根目录，无需构建流程。若需重新触发部署，可在仓库的 `Actions` 页面手动运行 `pages build and deployment` 工作流。
